# 금융 실험실 소개

**Polar Finance Lab**은 작은 은행을 직접 만들며 금융 백엔드와 분산 시스템을 공부하는 공간입니다.

계좌 하나에서 시작해 원장, 동시성, 은행 간 송금, 대사와 장애 복구까지 확장합니다. 기술을 적용한 이유와 실험 조건, 측정 결과, 남은 한계를 함께 기록합니다.

## 기록의 원칙

- 직접 확인한 결과와 가설을 구분합니다.
- 같은 조건에서 재현할 수 있도록 환경을 남깁니다.
- 성능과 정합성을 함께 확인합니다.
- 가상의 은행·거래 데이터를 사용합니다.
